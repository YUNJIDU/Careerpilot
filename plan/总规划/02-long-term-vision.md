# 长期模块候选（非当前交付清单）

更新：2026-09-05。当前需求与顺序只由[总体规划](03-mvp-plan.md)和[当前规则](../CURRENT-POLICY.md)定义。本文件不覆盖 Stage 5–6，也不因上游已有实现就自动加入近期范围。

| 候选 | 价值 | 启用边界 |
|---|---|---|
| H 申请问题草稿 | 复用岗位研究与个人证据回答申请问题 | 用户主动请求；不照搬 4.5 分触发，不自动填写/提交 |
| 求职信、申请邮件 | 基于研究形成材料草稿 | 用户需要且模型通过事实验收；不自动发送 |
| 谈薪与 Offer 辅助 | 整理条款、薪酬差距和待询问问题 | 独立设计，不代替用户决定 |
| 面试复盘、申请漏斗 | 根据真实记录总结过程 | 有足够数据再做，不猜测拒绝原因 |
| 语音、掌握度、长期训练 | 后续练习扩展 | 当前先完成清单、故事和一次文字模拟 |
| 简历格式/ATS 检查 | 检查可读性与格式 | 可单独评估，不隐含自动重写或生成 PDF |
| 更多邮箱与通知渠道 | 新用户实际需要时扩展 | 不接管邮箱、不无条件上多账户 |
| 云端 Web 与商业化 | 普通用户交付 | Stage 8 独立确定本地版政策、数据迁移与安全责任 |

研究资料、故事库与任务状态遵循 [Harness](../stages/stage-06-agent-orchestration.md)；不再维护另一套记忆或多 Agent 规划。候选获准后同步更新当前规则、Stage、总体顺序和验收。
