# Stage 8：生产部署与商业化

## 目标

核心功能稳定后，再把单用户本地工具演进为可发布、可运营的安全产品。
本阶段不是当前开发前置条件。

面向普通用户时，目标形态为云端 Web/SaaS。当前不决定本地版届时继续维护、作为社区版保留，还是由 SaaS 取代；核心业务模块和数据契约必须保持可移植。

## Open Core 策略

开源核心保留：

- 数据模型与 Application Core。
- Excel、邮箱、模型和 Agent 接口。
- 本地 Web 与本地部署能力。
- 插件规范、迁移机制和安全测试。

当前只保留接口、不编写实现：

- 支付。
- 配额。
- 运营系统。
- 托管凭证服务。
- 商业专属集成。

这些能力进入本 Stage 后再决定产品、许可证、部署和开源边界。

Open Core 当前采用 Apache License 2.0。面向 SaaS 的支付、配额、运营、托管凭证和商业集成仅在核心中保留版本化接口，不编写占位业务实现。

## WBS

### 8.1 本地发布与单用户部署

- Docker Compose。
- Windows 安装包。
- 自动更新与明确的回滚路径。
- PostgreSQL。
- 后台 Worker。
- 对象存储。
- HTTPS。
- 备份和恢复。

### 8.2 多租户

- 用户、组织和 RBAC/ABAC。
- 租户隔离。
- 数据导出和删除。
- API Key、配额和限流。

### 8.3 高并发

- 异步任务队列。
- Worker 扩缩容。
- 浏览器任务池。
- 模型限流和缓存。
- 幂等和重放保护。

### 8.4 生产安全

- CSRF、XSS、SSRF 和 SQL 注入防护。
- Prompt Injection 和数据外泄测试。
- 密钥轮换。
- 加密备份。
- 依赖和镜像扫描。
- 安全事件响应。

### 8.5 商业化

- Web 订阅。
- 本地授权版。
- 单次部署/交付。
- 渠道销售。
- 支付、订单和售后。
- 隐私政策、用户协议和供应商条款。

## 完成标准

- 用户数据、凭证和任务严格隔离。
- 系统可备份、恢复、监控和审计。
- 商业化前完成隐私、安全与条款审查。

## 产品化参考

- [Gsync/jobsync](https://github.com/Gsync/jobsync)：自托管 Web、账户、Tracker、Docker 部署和本地/云模型配置参考。
- [jobtopbob/jobtopbob](https://github.com/jobtopbob/jobtopbob)：自托管求职门户、邮箱集成和完整 Web 产品边界参考，进入本 Stage 时复核实现与许可证。

参考项目只用于比较部署、账户和用户体验，不替代 CareerPilot 的多租户隔离、凭证托管、删除权、审计和商业合规设计。
