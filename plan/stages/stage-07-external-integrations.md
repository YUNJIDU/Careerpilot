# Stage 7：外部自动化与人工确认辅助

## 定位

Stage 7 在 Stage 5–6 稳定后增加外部操作辅助。163 只读邮箱已经在 Stage 3 完成；Gmail/Outlook 不属于当前计划，有明确新需求时再单独设计。

## 候选能力

### 提醒、日历和通知

- 根据截止时间和面试时间生成本地提醒。
- 导出标准 ICS，由用户选择的日历负责长期提醒。
- 可选浏览器/系统通知。
- 规则计算、时间排序和 ICS 使用确定性代码，不使用 Agent。

### 浏览器表单辅助

- 在用户主动打开的申请页面识别字段。
- 从已确认的个人资料和当前简历生成字段候选值。
- 未知字段可由受控 Agent 解释并建议映射。
- 只预览或预填；验证码和最终提交始终由用户完成。
- 不绕过站点控制、反爬、登录、付费墙或服务条款。

### 回复与跟进草稿

- 根据岗位时间线生成跟进时间建议。
- 结合已确认事实生成邮件回复草稿。
- 不自动发送、不标记、不移动或删除邮箱内容。

## 安全边界

- 浏览器 Agent 使用独立最小权限工具，不接触 Credential Manager 明文。
- 每个网页或业务记录写入都显示字段、来源和目标并等待确认。
- 表单值只来自用户资料、当前简历和人工确认内容。
- 失败不得提交部分表单或改变 Application Core 状态。

## 明确延后

- Gmail/Outlook 和多邮箱；
- 后台常驻监控；
- 自动验证码处理；
- 自动投递、批量投递和自动提交；
- 反检测、代理池或规避平台限制。

每项能力均需独立设计、站点条款检查和浏览器隔离评审，不整体引入通用浏览器 Agent。
